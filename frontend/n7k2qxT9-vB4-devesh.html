What I built

The exam platform (AITTS, for Vibrant Academy)

A topic-wise test series for JEE aspirants: registration, timed exams, an all-India leaderboard, and an admin console — built to survive several hundred students hitting submit within the same few minutes, which is a very different engineering problem than most CRUD apps. It's sized for 500 concurrent test-takers today, moving toward 750–1000+, running on a two-core cloud instance behind Nginx.

PDF-to-test pipeline

Coaching institutes hand me question papers as PDFs, not structured data. I don't extract anything locally — the pages go straight to an AI API, which hands back the text, diagrams, and tables already structured into gradable questions. Cuts what used to be hours of manual entry per test down to a review pass.

Anti-cheating system

Exams run in enforced fullscreen; the client watches for tab switches, lost window focus, and fullscreen exits, and logs each one as a violation in real time. Three violations auto-submits the exam and pushes a live alert straight to the admin dashboard over a websocket, while progress and violation counts survive a refresh so a genuine accidental exit doesn't cost a student their answers.

Real-time infrastructure

Live leaderboards, moderated exam-day chat, and push notifications all run over Socket.IO. Underneath, student, test, and result data live on DynamoDB rather than MongoDB specifically because it holds up better under the bursty read/write pattern of an exam window, after I hit the limits of what a single-instance MongoDB setup could take under load.
